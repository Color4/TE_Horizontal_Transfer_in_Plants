# HTTs Atlas and Impacts on Plant Evolution
This repository contains the code for the manuscript titled "Decoding Horizontal Genetic Transfers and Their Role in Plant Evolution via a Comprehensive HTT Atlas"

# Content

Pipelines and relevant scripts for:

- 01.Genome_Annotation
- 02.Function_Gene_and_ncRNA Annotation
- 03.Phylogenetic_Analysis
- 04.HTTs Detection
- 05.Co-HT Network Analysis
- 06.HTT Related Gene Enrichment Analysis
- 07. Detection of HTT seqs in exosome-seq data
- 08. Search for HTT homologous seqs in NCBI NR DB
